# Library Management System

## Overview

Library Management System is a web application developed for the IT Project Management course at Phenikaa University.

The system helps librarians manage books and allows users to search, borrow, and return books efficiently. The project is developed following Agile/Scrum methodology and managed using Jira and GitHub.

---

## Features

- User Login and Authentication
- Book Management
- Search Books
- Borrow Books
- Return Books
- View Borrowing History
- Library Dashboard

## Installation

Clone repository:

```bash
git clone https://github.com/your-organization/library-management-system.git
```

Move to project folder:

```bash
cd library-management-system
```

Install dependencies:

```bash
npm install
```

Run application:

```bash
npm start
```
